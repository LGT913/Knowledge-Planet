### 第 4 周 星期四（第 19 天）
- **今日目标**：引入 WebSocket，实现实时推送通知
- **项目改造任务**：
  - 修改文件：`blog/pom.xml`（添加 WebSocket 依赖）
    ```xml
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-websocket</artifactId>
    </dependency>
    ```
  - 新建文件：`blog/src/main/java/com/blog/blog/config/WebSocketConfig.java`
    ```java
    @Configuration
    @EnableWebSocketMessageBroker
    public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {
        @Override
        public void registerStompEndpoints(StompEndpointRegistry registry) {
            registry.addEndpoint("/ws/notify")
                    .setAllowedOriginPatterns("*")
                    .withSockJS();
        }
        
        @Override
        public void configureMessageBroker(MessageBrokerRegistry registry) {
            registry.enableSimpleBroker("/topic", "/queue");
            registry.setApplicationDestinationPrefixes("/app");
        }
    }
    ```
  - 修改文件：`blog/src/main/java/com/blog/blog/service/CommentNotifyConsumer.java`
    ```java
    // 在消费方法末尾添加
    @Autowired
    private SimpMessagingTemplate messagingTemplate;
    
    // 推送给文章作者
    String destination = "/topic/article/" + articleId + "/comments";
    messagingTemplate.convertAndSend(destination, message);
    ```
  - 预期效果：用户在文章详情页时能实时收到新评论通知
- **核心知识点**：
  - 学习内容：WebSocket 原理（全双工通信）、STOMP 协议、和 HTTP 的区别
  - 学习资源：[Spring WebSocket 官方文档](https://docs.spring.io/spring-framework/reference/web/websocket.html)
- **LeetCode刷题**：
  - 题目：[155. 最小栈](https://leetcode.cn/problems/min-stack/)（考察：辅助栈）
- **今日检查项**：
  - [ ] WebSocket 连接建立成功（浏览器控制台不报错）
  - [ ] 新评论时能收到实时推送
- **常见问题与解决方案**：
  - SockJS 跨域问题：`setAllowedOriginPatterns("*")` 允许所有来源
  - 前端需要引入 `sockjs-client` 和 `stompjs`（npm install）
