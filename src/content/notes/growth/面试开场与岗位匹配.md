## 十、面试开场与岗位匹配

### 问题 18：请做一个自我介绍（45-90秒）

**问题本身**：
> 问：请用45到90秒做一个自我介绍，重点讲清楚你的技术背景、最有代表性的项目，以及你为什么觉得自己适合后端开发实习生这个岗位。

**为什么要这么做**：
- 自我介绍是面试的第一印象，要突出技术背景和项目亮点
- 要关联岗位要求，展示匹配度

**具体怎么做**：
```
面试官好，我是XX，计算机相关专业。
我做一个校园快递管理系统项目，主要解决了两个痛点：一是校园快递从派送到签收的全流程管理，二是学生代取需求与兼职供给的信息不联通。
我负责整个后端的设计和开发，技术栈是 Spring Boot + MyBatis + MySQL，单体架构足够这个项目。
后端采用 MVC 三层架构，设计了 7 个模块、6 张表。
我成长比较多的是统计模块，从全表查询+Java 过滤优化到 SQL 层 COUNT+WHERE 配合索引，性能提升了 30 倍。
整个项目核心业务流程都能跑通，四种角色从登录到签收、从发布到送达，全链路正常。
```

**如何验证**：
1. 计时练习，控制在 45-90 秒内
2. 确保包含技术背景、项目亮点、岗位匹配三个要素

---

### 问题 19：你觉得自己最能直接上手的是哪一块？

**问题本身**：
> 问：如果对照我们这个后端实习岗位，你觉得自己最能直接上手的是哪一块？为什么？

**为什么要这么做**：
- 展示自己的核心竞争力，说明入职后能快速产出价值

**具体怎么做**：
```
我觉得是接口开发和数据库操作。
我的项目从头到尾都是自己设计数据库、写接口、做自测，整个流程很熟练。
入职后如果分给我一个简单业务接口，我能独立完成从数据库设计到接口实现到自测的全流程。
```

**如何验证**：
1. 能说出具体的接口开发流程
2. 能说出自测方法（Postman、断点调试、EXPLAIN）

---

### 问题 20：入职前两周分给你一个简单业务接口，你能交付到什么程度？

**问题本身**：
> 问：如果入职前两周我分给你一个简单业务接口，你觉得你能独立交付到什么程度？比如除了写代码，你会怎么做自测，最后交付哪些东西？

**为什么要这么做**：
- 展示自己的工作流程和交付标准
- 说明自己不仅会写代码，还会做自测和文档

**具体怎么做**：
```
除了写代码，我会：
1. 先和导师对齐接口文档（字段名、类型、含义）
2. 写完后用 Postman 自测正常流程和异常流程
3. 最后交付：可运行的代码 + 接口文档 + 自测报告（覆盖正常/异常/边界情况）
```

**如何验证**：
1. 能说出完整的交付流程
2. 能说出自测的具体方法
3. 能说出交付物清单

---

## 总结

以上是基于 3 次模拟面试和多条技术专家对话整理的完整追问笔记。每个问题都按照"问题本身→为什么→怎么做→如何验证"的结构作答，并且都结合了项目实战经验。

**复习建议**：
1. 先通读一遍，了解所有问题和追问链路
2. 重点复习带 ⚠️ 标记的问题（高频考点）
3. 按模块逐一复习，理解知识关联
4. 模拟面试场景，尝试脱稿回答

**面试技巧**：
1. 回答问题时，先讲业务场景，再讲技术方案，最后说为什么这么选
2. 每个知识点都要关联项目中的具体应用
3. 遇到不会的问题，诚实说明，但可以说"我了解相关的..."
4. 保持自信，声音清晰，语速适中
