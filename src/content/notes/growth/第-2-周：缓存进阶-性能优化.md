  - 新建文件：`blog/src/main/java/com/blog/blog/config/RedissonConfig.java`
    ```java
    @Configuration
    public class RedissonConfig {
        @Value("${spring.data.redis.host}")
        private String redisHost;
        @Value("${spring.data.redis.port}")
        private int redisPort;
        
        @Bean
        public RedissonClient redissonClient() {
            Config config = new Config();
            config.useSingleServer()
                  .setAddress("redis://" + redisHost + ":" + redisPort);
            return Redisson.create(config);
        }
    }
    ```
  - 新建文件：`blog/src/main/java/com/blog/blog/common/BloomFilterUtil.java`
    ```java
    @Component
    public class BloomFilterUtil {
        private static final String BLOOM_FILTER_KEY = "article:bloom";
        
        @Autowired
        private RedissonClient redissonClient;
        
        /**
         * 初始化布隆过滤器
         * @param expectedInsertions 预期数量
         * @param falseProbability 误判率
         */
        public RBloomFilter<Long> getArticleBloomFilter() {
            RBloomFilter<Long> bloomFilter = redissonClient
                    .getBloomFilter(BLOOM_FILTER_KEY);
            bloomFilter.tryInit(10000L, 0.01);  // 1 万个元素，1% 误判率
            return bloomFilter;
        }
        
        // 新增文章 ID 到布隆过滤器
        public void add(Long articleId) {
            RBloomFilter<Long> bloomFilter = getArticleBloomFilter();
            bloomFilter.add(articleId);
        }
        
        // 判断文章 ID 是否可能存在
        public boolean mightContain(Long articleId) {
            RBloomFilter<Long> bloomFilter = getArticleBloomFilter();
            return bloomFilter.mightContain(articleId);
        }
    }
    ```
  - 修改文件：`blog/src/main/java/com/blog/blog/service/impl/ArticleServiceImpl.java`（在 createArticle 中调用 bloomFilter.add）
    ```java
    // 第 33 行附近：注入 BloomFilterUtil

    private BloomFilterUtil bloomFilterUtil;
    
    // createArticle 方法中，save 之后添加：
    bloomFilterUtil.add(article.getId());
    
    // getArticle 方法中，查数据库之前先判断：
    if (!bloomFilterUtil.mightContain(id)) {
        throw new RuntimeException("文章不存在");  // 直接拦截，不进数据库
    }
    ```
  - 预期效果：不存在文章 ID 的请求被布隆过滤器拦截，不查询数据库
- **核心知识点**：

  - 学习资源：[Redisson 官方 - Bloom Filter](https://github.com/redisson/redisson/wiki/6.-Distributed-objects#67-bloom-filter)
- **LeetCode刷题**：

  - 新增文件 `blog/src/main/java/com/blog/blog/controller/SearchController.java`
    ```java
    @RestController
    @RequestMapping("/api/article")
    public class SearchController {
        @Autowired
        private ArticleRepository articleRepository;
        
        @GetMapping("/search")
        public Result<List<Article>> search(@RequestParam String keyword) {
            if (keyword == null || keyword.trim().isEmpty()) {
                return Result.success(Collections.emptyList());
            }
            List<Article> articles = articleRepository.searchByKeyword(keyword.trim());
            return Result.success(articles);
        }
    }
    ```
