### 第 5 周 星期四（第 24 天）
- **今日目标**：使用 OpenFeign 实现服务间调用（文章服务调用用户服务）
- **项目改造任务**：
  - 修改文件：`blog-cloud/blog-article-service/pom.xml`
    ```xml
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-starter-openfeign</artifactId>
    </dependency>
    ```
  - 新建文件：`blog-cloud/blog-article-service/src/main/java/com/blog/article/feign/UserFeignClient.java`
    ```java
    @FeignClient(name = "user-service")
    public interface UserFeignClient {
        
        @GetMapping("/api/user/{id}")
        Result<UserDTO> getUserById(@PathVariable("id") Long id);
    }
    
    // UserDTO（轻量级 DTO，只包含需要的字段）
    @Data
    public class UserDTO {
        private Long id;
        private String username;
        private String nickname;
    }
    ```
  - 修改文件：`blog-cloud/blog-article-service/src/main/java/.../ArticleController.java`
    ```java
    @GetMapping("/{id}")
    public Result<ArticleVO> getArticle(@PathVariable Long id) {
        Article article = articleService.getArticle(id);
        // 通过 Feign 调用用户服务获取作者信息
        Result<UserDTO> userResult = userFeignClient.getUserById(article.getUserId());
        ArticleVO vo = new ArticleVO();
        BeanUtils.copyProperties(article, vo);
        if (userResult.getCode() == 200 && userResult.getData() != null) {
            vo.setAuthorName(userResult.getData().getNickname());
        }
        return Result.success(vo);
    }
    ```
  - 在 `ArticleApplication.java` 添加 `@EnableFeignClients` 注解
  - 预期效果：查看文章详情时返回文章数据 + 作者昵称
- **核心知识点**：
  - 学习内容：Feign 声明式 HTTP 客户端、服务间鉴权（token 传递）、DTO 设计模式
  - 学习资源：[Spring Cloud OpenFeign 官方文档](https://docs.spring.io/spring-cloud-openfeign/docs/current/reference/html/)
- **LeetCode刷题**：
  - 题目：[912. 排序数组](https://leetcode.cn/problems/sort-an-array/)（考察：快排/归并排序）
- **今日检查项**：
  - [ ] 文章服务能通过 Feign 调用用户服务
  - [ ] 文章详情 API 返回了作者昵称（之前只有 userId）
- **常见问题与解决方案**：
  - Feign 调用超时：配置 `spring.cloud.openfeign.client.config.default.connect-timeout=5000`
  - `@EnableFeignClients` 扫描不到 FeignClient：指定 `basePackages = {"com.blog.article.feign"}`
