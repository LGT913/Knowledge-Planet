## C. 项目亮点 & Bug 修复

### C.1 统计模块性能优化（30 倍）

> ⚠️ 面试最高频题，必须能脱稿复述完整过程

- **背景**：管理员仪表盘统计响应 2-3 秒
- **定位**：分段计时，Java Stream 过滤占 90%
- **方案**：全表查+Java过滤 → SQL `COUNT(*) + WHERE` + 索引
- **结果**：2-3 秒 → 50-80 毫秒
- **验证**：预热+5轮+清缓存+EXPLAIN（type: ALL→ref, rows: 5000→15）

### C.4 Bug 修复：注册成功但登录失败

| 项目 | 内容 |
|------|------|
| 问题 | 用户注册成功但登录显示失败 |
| 定位 | 断点调试+查数据库，发现前端未传username字段，后端自动生成username |
| 解决 | 注册接口加username字段，登录接口用username登录 |
| 教训 | 先写接口文档再开发，前后端联调前先对齐字段名/类型/含义 |
