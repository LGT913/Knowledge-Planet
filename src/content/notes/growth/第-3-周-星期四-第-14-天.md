### 第 3 周 星期四（第 14 天）
- **今日目标**：实现"浏览记录"异步持久化 + 点赞功能（用 RabbitMQ 解耦）
- **项目改造任务**：
  - 修改文件：`blog/src/main/java/com/blog/blog/entity/Article.java`（新增点赞数字段）
    ```java
    @Column(columnDefinition = "int default 0")
    private Integer likeCount = 0;
    ```
  - 新建文件：`blog/src/main/java/com/blog/blog/controller/LikeController.java`
    ```java
    @RestController
    @RequestMapping("/api/like")
    public class LikeController {
        @Autowired
        private RabbitTemplate rabbitTemplate;
        @Autowired
        private RedisUtil redisUtil;
        
        @PostMapping("/article/{articleId}")
        public Result<String> likeArticle(@PathVariable Long articleId) {
            String key = "blog:article:like:" + articleId;
            redisUtil.increment(key);  // Redis 自增
            
            // 异步发送点赞消息
            Map<String, Object> msg = new HashMap<>();
            msg.put("articleId", articleId);
            msg.put("timestamp", System.currentTimeMillis());
            rabbitTemplate.convertAndSend("blog.like.exchange", "blog.like.save", msg);
            
            return Result.success("点赞成功");
        }
    }
    ```
  - 在 `RabbitMQConfig.java` 中新增点赞相关的 Exchange/Queue/Binding
  - 预期效果：点赞时秒级响应（Redis 自增），后台异步同步到数据库
- **核心知识点**：
  - 学习内容：消息确认机制（ConfirmCallback/ReturnCallback）、手动 ACK、死信队列
  - 学习资源：[Spring AMQP - Async Template](https://docs.spring.io/spring-amqp/reference/amqp/async-template.html)
- **LeetCode刷题**：
  - 题目：[21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)（考察：链表合并）
- **今日检查项**：
  - [ ] 点赞后 Redis 中的计数 +1
  - [ ] 消息能正常发送和消费
  - [ ] 数据库点赞数最终一致
- **常见问题与解决方案**：
  - 多次点赞同一个人怎么办：后续加 Redis Set 去重，或用布隆过滤器判断是否已点赞
  - 数据库同步有延迟：给前端提示"点赞已记录，数据同步中"
