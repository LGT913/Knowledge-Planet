# 📅周计划模板（9.10 开始，第一周示范，你可以直接落地）

> 每周固定产出，不要只是看书看视频，每周要有可交付产物。

## 第 1 周（9.10‑9.16）

1. 并发：线程基础、线程状态、JMM、volatile、synchronized 锁升级；demo 复现可见性 bug。
2. MySQL：B + 树索引，聚簇 / 非聚簇索引，explain；拿博客文章表分析索引。
3. 算法：Hot100 数组、链表；周末一套牛客模拟笔试。
4. 简历：开始第一版简历修订，梳理博客项目所有技术点；开始写并发架构文档初稿。
5. 求职：整理简历，开始投递第一批公司。

## 第 2 周（9.17‑9.23）

1. 并发：AQS 骨架、ReentrantLock、CAS、ABA；demo 复现 ABA；CountDownLatch/CyclicBarrier/Semaphore；
2. Redis：基础数据结构底层，过期淘汰，缓存三防；整理博客缓存三防口述答案。
3. Spring：@Transactional，事务传播、隔离、事务失效场景，demo 复现失效。
4. 算法：树 BFS、DFS，哈希；二刷上周错题。
5. 项目：开始评审博客两个线程池，写`线程池设计说明.md`初稿。

## 第 3 周（9.24‑9.30）

1. 并发：线程池七大参数、拒绝策略；CompletableFuture 学习；**启动博客热点排行接口改造**；死锁 demo + jstack。
2. MySQL：MVCC、undo/redo log，四大隔离级别，行锁 / 间隙锁 / 临键锁。
3. MQ：RabbitMQ 消息可靠性、幂等、积压；结合博客评论通知整理口述。
4. JVM（开始碎片化）：内存五大区、对象头、类加载、双亲委派。
5. 算法：栈、队列，二分；周末模拟笔试。

## 第 4‑5 周（10.1‑10.15）

1. 并发收尾：ConcurrentHashMap1.7/1.8；ThreadLocal 坑；**完成 CompletableFuture 接口改造，提交代码，完善三份架构文档；完成「本地锁‑MySQL 锁‑Redis 分布式锁」对比笔记**。
2. JVM 继续高频子集：GC 分代、G1/ZGC、OOM 类型、jstack/jmap Arthas 基础。
3. Redis 收尾：Redisson 分布式锁、锁续期、主从哨兵集群概念。
4. 八股笔记全部迭代，项目全套口述稿完成。
5. 算法持续刷题、二刷错题；大量投递，密集参加笔试面试，面试结束立刻复盘漏洞。
