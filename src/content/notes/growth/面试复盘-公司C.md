# 公司CJava秋招 · 3周压缩笔试冲刺计划（瞄准9.19第二批笔试）

> 前提

1. 每日底线：工作日≥3h，周末≥6h；**算法每天必写代码，禁止只看题**
2. 并行要求：每天抽**30分钟复盘博客项目面试话术**，防止突发面试
3. 取舍：放弃Hard算法、冷门源码，只抓笔试高频考点；第一批9.05收到笔试直接当模拟，不纠结结果
4. 工具：牛客网Java选择题、LeetCode（简单/中等）、自己建错题文档，**所有错题必须记录错误原因**

> 时间分配模板（工作日3‑4h）

- 八股+选择题：1.5h
- 算法编码：1h
- 错题复盘+项目复盘：0.5‑1h

> 周末6‑8h模板

- 整套限时模拟笔试（2.5h，严格计时）
- 错题深挖2h
- 算法专项1.5h
- 项目话术复盘0.5‑1h

------

## 第1周｜Java核心 + JVM + OS + 计算机网络（共7天）

目标：拿下选择题半壁江山；搞定多线程、JVM高频简答；补齐薄弱的计网、操作系统。

> 算法本周主题：数组 + 链表（每天2题：1简单 +1中等）

### Day1 Java多线程核心

1. 背诵&刷题
   - 线程状态、start()/run()；synchronized锁升级；volatile；CAS&ABA；AQS基础
   - ThreadLocal底层、内存泄漏；CountDownLatch / CyclicBarrier / Semaphore对比
2. 选择题：牛客Java并发25道
3. 算法：链表反转、环形链表检测
4. 复盘30min：博客项目线程池相关面试话术

### Day2 线程池 + JVM内存模型

1. 背诵&刷题
   - ThreadPoolExecutor七大参数、4种拒绝策略、执行流程；Executors弊端；allowCoreThreadTimeOut
   - JVM五大内存区域，每个区域OOM场景；对象内存布局；访问对象方式
2. 选择题：线程池+JVM选择25道
3. 算法：合并两个有序链表、删除链表倒数N节点
4. 整理错题

### Day3 JVM GC + 类加载

1. 背诵&刷题
   - 可达性分析；四种引用；GC算法；收集器CMS / G1 / ZGC重点特性
   - 类加载5阶段、双亲委派模型，破坏场景
   - jps/jstat/jmap/jstack作用，OOM排查思路
2. 选择题25道
3. 算法：双指针：三数之和
4. 简答默写题：手写CMS工作流程；双亲委派机制

### Day4 集合框架 + Java基础坑点

1. 背诵&刷题
   - HashMap1.7/1.8；ConcurrentHashMap；ArrayList/LinkedList；fail‑fast
   - Integer缓存、String常量池、重载重写、接口抽象类、值传递
2. 选择题30道
3. 算法：滑动窗口（无重复字符的最长子串）
4. 错题复盘

### Day5 计算机网络（重点背）

1. 背诵&刷题
   - TCP/IP四层；三次握手、四次挥手；TIME_WAIT、CLOSE_WAIT
   - 滑动窗口、拥塞控制；TCP vs UDP
   - HTTP1.1/2/3；HTTPS TLS握手；Cookie、Session、CORS跨域
2. 计网选择题30道
3. 算法：数组：前缀和子数组
4. 简答默写：简述HTTPS完整流程

### Day6 操作系统

1. 背诵&刷题
   - 进程线程区别；进程状态；死锁4个必要条件；虚拟内存
   - 用户态/内核态；分页分段；IO模型BIO/NIO/AIO；零拷贝
2. OS选择题25道
3. 算法专项：数组、链表错题二刷
4. 默写：BIO/NIO/AIO区别，零拷贝原理

### Day7 周末｜第1周全量复盘 + 模拟

1. 限时做一套牛客Java客观题整套（选择填空，90分钟）
2. 全部错题复盘，归类：并发 / JVM / OS / 计网
3. 算法：链表+数组错题重写
4. 30min复习项目：线程池、ThreadLocal、并发相关问答

> 第1周结束验收标准：

- 并发、JVM选择题错题率 ≤25%；能手写简答核心原理；数组链表中等题可以独立写代码。

## 第2周｜MySQL + Redis + MQ + Spring全家桶（7天）

目标：搞定数据库、中间件笔试简答、SQL手写；这部分和你的博客项目高度重合，重点补笔试坑、SQL、explain。

> 算法本周主题：二叉树 + 堆TopK（游戏排行榜必考，每天2题）

### Day8 MySQL索引

1. 背诵刷题
   - InnoDB B+树、聚簇/二级索引、回表、覆盖索引；最左前缀；索引失效全部场景
   - explain字段type、key、Extra含义
2. 选择25道；手写3道SQL练习多表join
3. 算法：二叉树层序遍历，二叉树最大深度
4. 项目复盘：博客索引设计问答

### Day9 MySQL事务与锁

1. 背诵刷题
   - ACID；4隔离级别；MVCC、undo log、read‑view；RC/RRR区别
   - 行锁、表锁、意向锁；记录锁、Gap锁、临键锁
   - redo/undo/binlog，两阶段提交；长事务危害
2. 选择题25道；练习窗口函数 `row_number() rank() dense_rank()`（排行榜笔试必考）
3. 算法：二叉树最近公共祖先
4. 手写简答：MVCC实现原理

### Day10 MySQL进阶 + SQL强化

1. 背诵刷题
   - 大表分页问题；慢SQL排查；分库分表基础；读写分离
2. **手写SQL训练5道：分组、多表、分页、窗口函数排行榜模拟**
3. 算法：TopK（堆解法）
4. 整理SQL错题

### Day11 Redis全套（重中之重，游戏笔试高频）

1. 背诵刷题
   - 5大结构，Sorted‑Set跳表；持久化RDB/AOF；过期策略；8种内存淘汰策略
   - 缓存穿透、击穿、雪崩全套方案；分布式锁、Redisson看门狗
   - 主从、哨兵、RedisCluster哈希槽
2. 选择题30道
3. 算法：TopK变式
4. 简答默写：缓存三防完整方案；Redisson看门狗机制

### Day12 RabbitMQ + SpringIOC/AOP

1. 背诵刷题
   - MQ交换机类型；消息丢失、重复消费、幂等、死信队列、消息积压处理
   - Spring Bean生命周期；三级缓存循环依赖；JDK/CGLIB动态代理
2. 选择题25道
3. 算法：二叉树错题二刷
4. 项目复盘：MQ可靠性、幂等问答

### Day13 Spring事务 + SpringBoot自动装配

1. 背诵刷题
   - @Transactional：7种传播行为、5种隔离级别；**事务失效全部场景（笔试高频简答）**
   - @EnableAutoConfiguration自动装配原理
2. 选择题25道
3. 算法：堆、TopK错题重写
4. 手写简答：Spring事务什么时候会失效？

### Day14 周末｜第2周模拟测试

1. 限时模拟：数据库+Redis+MQ+Spring客观题整套90min
2. 错题深度复盘，把事务失效、索引失效、缓存三防整理成一页速记
3. 算法：二叉树+TopK刷题复盘
4. 项目复盘：缓存三防、分布式锁、MQ整套项目口述一遍

> 第2周验收：可以独立写窗口函数实现排行榜；缓存、事务、索引简答可以完整默写；TopK可以手写堆解法。

## 第3周｜分布式理论 + 三七游戏业务题 + 算法综合 + 全真套卷冲刺（7天）

> 算法主题：滑动窗口、前缀和、简单DP、**游戏业务模拟编程题（三七特色）**

### Day15 分布式基础理论

1. 背诵刷题
   - CAP、BASE；雪花算法分布式ID；限流算法：固定窗口/滑动窗口/漏桶/令牌桶
   - 限流熔断降级概念
2. 分布式选择题25道
3. 算法：滑动窗口、前缀和
4. 简答默写：四种限流算法优缺点对比

### Day16 分布式事务

1. 背诵刷题
   - 2PC、3PC；TCC；Seata AT；本地消息表、可靠消息最终一致性
   - 优先最终一致性思想，不要滥用强分布式事务
2. 选择题20道
3. 算法：简单DP（0‑1背包基础）
4. 简答默写：本地消息表实现最终一致性流程

### Day17 三七特色笔试业务简答题（核心！区别普通互联网）

> 全部整理成答题模板，手写一遍

1. 全服排行榜设计（Redis SortedSet + DB兜底）
2. 大量玩家并发领取限时道具，防重复、防超发
3. 玩家数据内存定时批量落库设计思路
4. MQ实现游戏邮件道具发放如何避免重复发放
5. 游戏网关长连接需要考虑哪些问题（Netty、心跳、拆包粘包）
6. 热点玩家数据缓存击穿如何处理

- 算法：**业务模拟题1道（模拟签到系统逻辑编码）**

### Day18 编程模拟训练 + SQL总复习

1. SQL整套复习：窗口函数、join、group by，再手写4道
2. 练习2道**游戏业务模拟编程题**（比如道具扣减、签到统计）
3. 算法：综合刷题（数组/链表/树/模拟混合）
4. 回顾全部错题文档，看选择填空错题

### Day19 综合错题回滚

1. 把第1‑2周错题，重新过一遍，标记仍然做错的重难点
2. 算法：刷之前做错所有中等题，**必须手敲完整代码**
3. 背诵：所有简答默写题快速过一遍（JVM、MVCC、缓存三防、限流、游戏业务题）

### Day20 周末｜全真完整笔试模拟1（严格计时，模拟真实三七笔试时长2.5h）

> 包含：选择+填空+SQL+2道算法+1道业务简答，完全模拟考场，不查资料。

1. 做完之后逐题复盘，统计丢分模块，针对性补短板
2. 项目完整口述一遍博客项目，模拟面试官拷打

### Day21 考前最后一天｜冲刺复盘

1. 不再做大量新题！只看：**错题本 + 简答速记页 + 三七游戏业务答题模板**
2. 算法只复习之前写过的高频题，不刷新难题
3. 再过一遍简历项目全部话术，做好笔试之后随时面试的准备

> 第3周验收：

1. 游戏业务简答全部有成型答题模板；
2. 遇到业务模拟编程，能读懂需求、写出可运行核心逻辑；
3. 整套模拟笔试分数稳定达到及格以上。
