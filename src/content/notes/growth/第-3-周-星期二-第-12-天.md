### 第 3 周 星期二（第 12 天）
- **今日目标**：实现评论异步通知（用户评论文章后，异步通知文章作者）
- **项目改造任务**：
  - 新建文件：`blog/src/main/java/com/blog/blog/config/RabbitMQConfig.java`
    ```java
    @Configuration
    public class RabbitMQConfig {
        public static final String COMMENT_EXCHANGE = "blog.comment.exchange";
        public static final String COMMENT_QUEUE = "blog.comment.queue";
        public static final String COMMENT_ROUTING_KEY = "blog.comment.notify";
        
        @Bean
        public TopicExchange commentExchange() {
            return new TopicExchange(COMMENT_EXCHANGE);
        }
        
        @Bean
        public Queue commentQueue() {
            return new Queue(COMMENT_QUEUE, true);  // durable=true
        }
        
        @Bean
        public Binding commentBinding() {
            return BindingBuilder.bind(commentQueue())
                    .to(commentExchange())
                    .with(COMMENT_ROUTING_KEY);
        }
    }
    ```
  - 新建文件：`blog/src/main/java/com/blog/blog/service/NotifyService.java`
    ```java
    @Service
    public class NotifyService {
        @Autowired
        private RabbitTemplate rabbitTemplate;
        
        /**
         * 发送评论通知消息
         */
        public void sendCommentNotify(Long articleId, Long commentUserId, String commentContent) {
            Map<String, Object> message = new HashMap<>();
            message.put("articleId", articleId);
            message.put("commentUserId", commentUserId);
            message.put("commentContent", commentContent);
            message.put("timestamp", System.currentTimeMillis());
            
            rabbitTemplate.convertAndSend(
                RabbitMQConfig.COMMENT_EXCHANGE,
                RabbitMQConfig.COMMENT_ROUTING_KEY,
                message
            );
        }
    }
    ```

  - 修改文件：`blog/src/main/java/com/blog/blog/controller/CommentController.java`
    ```java
    // 在 createComment 方法中，保存评论后调用异步通知
    @Autowired
    private NotifyService notifyService;
    
    @PostMapping("/create")
    public Result<Comment> create(@RequestBody Comment comment) {
        Comment createdComment = commentService.createComment(
                comment.getArticleId(), comment.getUserId(),
                comment.getContent(), comment.getParentId());
        
        // 异步发送通知（不阻塞主流程）
        notifyService.sendCommentNotify(
                comment.getArticleId(), comment.getUserId(), comment.getContent());
        
        return Result.success(createdComment);
    }
    ```
