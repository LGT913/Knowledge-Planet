## 五、计算机网络

### 1. HTTP / HTTPS（⭐⭐⭐⭐⭐）

**HTTP 状态码**

| 状态码 | 含义 |
|--------|------|
| 200 | OK 成功 |
| 301 | 永久重定向 |
| 302 | 临时重定向 |
| 304 | 协商缓存命中 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
| 502 | 网关错误 |
| 503 | 服务不可用 |

**HTTP 和 HTTPS 区别**

| 对比项 | HTTP | HTTPS |
|--------|------|-------|
| 端口 | 80 | 443 |
| 安全性 | 明文，不安全 | SSL/TLS 加密，安全 |
| 速度 | 快 | 稍慢（加密解密） |
| 证书 | 不需要 | 需要 CA 证书 |

**HTTPS 连接过程（TLS 握手）**

1. 客户端发送 Client Hello（支持的加密套件、随机数）
2. 服务端返回 Server Hello（选中的加密套件、随机数）+ 证书
3. 客户端验证证书，生成预主密钥，用服务端公钥加密发给服务端
4. 服务端解密得到预主密钥
5. 双方用三个随机数生成会话密钥
6. 后续用对称加密通信

**HTTP 1.0 / 1.1 / 2.0 区别**

- 1.0：短连接，每次请求都要建连接
- 1.1：长连接（keep-alive）、管道化、断点续传
- 2.0：二进制分帧、多路复用、头部压缩、服务器推送

### 2. TCP / UDP（⭐⭐⭐⭐）

**TCP 和 UDP 区别**

| 对比项 | TCP | UDP |
|--------|-----|-----|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠（重传、流量控制、拥塞控制） | 不可靠 |
| 速度 | 慢 | 快 |
| 首部大小 | 20-60 字节 | 8 字节 |
| 应用场景 | HTTP、FTP、邮件 | DNS、视频会议、直播 |

**TCP 三次握手**

1. 客户端 → 服务端：SYN，seq=x
2. 服务端 → 客户端：SYN+ACK，seq=y，ack=x+1
3. 客户端 → 服务端：ACK，seq=x+1，ack=y+1

为什么三次？防止已失效的连接请求报文段突然又传到服务端。

**TCP 四次挥手**

1. 客户端 → 服务端：FIN（我发完了）
2. 服务端 → 客户端：ACK（我知道了，等我发完）
3. 服务端 → 客户端：FIN（我也发完了）
4. 客户端 → 服务端：ACK（收到，等 2MSL 后关闭）

为什么四次？服务端收到 FIN 时可能还有数据没发完，不能一起发 FIN+ACK。

**TIME_WAIT 状态**

- 主动关闭的一方会进入 TIME_WAIT
- 等待 2MSL（最长报文寿命）
- 原因：
  1. 保证最后一个 ACK 能到达服务端
  2. 防止旧连接的报文段出现在新连接中

**TCP 可靠传输怎么保证？**

1. 校验和
2. 序列号 + 确认应答
3. 超时重传
4. 流量控制（滑动窗口）
5. 拥塞控制（慢开始、拥塞避免、快重传、快恢复）

### 3. Socket（⭐⭐⭐）

**什么是 Socket？**

- 套接字，是 TCP/IP 协议的抽象，是网络通信的端点
- 一个 Socket 由 IP + 端口号 唯一标识

**Socket 通信流程**

服务端：
1. socket() 创建套接字
2. bind() 绑定 IP 和端口
3. listen() 监听
4. accept() 阻塞等待连接
5. read() / write() 读写数据
6. close() 关闭

客户端：
1. socket() 创建套接字
2. connect() 连接服务端
3. write() / read() 读写数据
4. close() 关闭

**BIO / NIO / AIO**

- BIO：同步阻塞，一个连接一个线程
- NIO：同步非阻塞，一个线程管多个连接（Selector 多路复用）
- AIO：异步非阻塞，完成后回调

### 4. Nginx / Tomcat（⭐⭐⭐）

**Nginx 作用**

1. 反向代理
2. 负载均衡
3. 静态资源服务器
4. 动静分离

**Nginx 负载均衡策略**

1. 轮询（默认）
2. 加权轮询
3. ip_hash（按 IP 哈希，解决 session 问题）
4. least_conn（最少连接）
5. fair（响应时间）

**Tomcat 是什么**

- Servlet 容器，运行 Java Web 应用
- 处理 JSP、Servlet 等动态请求
