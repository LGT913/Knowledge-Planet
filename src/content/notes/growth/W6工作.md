# W6（D36‑D42）阶段5：全文自检（规则引擎 + LLM + 前端标注）｜工作文档

> 对应 `04-带时间的工作计划表.md` §阶段5，Git Tag **v0.6**，里程碑 **M6**：全文自检标红替换闭环。
> 🟢 阶段铁律：`/api/ai/check` 为**普通 JSON 接口（非 SSE）**；规则引擎（词级）为 **v1.0 必做**、纯函数无 IO；LLM 语义级检查**非法 JSON 优雅降级**（仅返回规则结果，不报错）。
> ⚠️ 标红裁剪点（重要）：v1.0 **不做实时标红**。仅点击【全文自检】才执行一次校验并生成 Decoration；用户一旦编辑输入即**清空全部标记**，再次点击自检才重建。以此规避高频重算 offset 映射的性能开销。
