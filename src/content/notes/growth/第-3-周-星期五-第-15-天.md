### 第 3 周 星期五（第 15 天）
- **今日目标**：RabbitMQ 高级特性（死信队列 + 延迟队列）
- **项目改造任务**：
  - 修改文件：`blog/src/main/java/com/blog/blog/config/RabbitMQConfig.java`
    ```java
    // 新增：死信队列配置（处理消费失败的消息）
    public static final String DLX_EXCHANGE = "blog.dlx.exchange";
    public static final String DLX_QUEUE = "blog.dlx.queue";
    public static final String DLX_ROUTING_KEY = "blog.dlx";
    
    // 新增订单延迟队列（模拟定时任务）
    public static final String DELAY_EXCHANGE = "blog.delay.exchange";
    public static final String DELAY_QUEUE = "blog.delay.queue";
    public static final String DELAY_ROUTING_KEY = "blog.delay";
    
    @Bean
    public Queue summaryQueue() {
        Map<String, Object> args = new HashMap<>();
        // 设置死信交换机和路由键
        args.put("x-dead-letter-exchange", DLX_EXCHANGE);
        args.put("x-dead-letter-routing-key", DLX_ROUTING_KEY);
        // 消息存活 5 分钟
        args.put("x-message-ttl", 300000);
        return new Queue(SUMMARY_QUEUE, true, false, false, args);
    }
    
    @Bean
    public DirectExchange dlxExchange() {
        return new DirectExchange(DLX_EXCHANGE);
    }
    
    @Bean
    public Queue dlxQueue() {
        return new Queue(DLX_QUEUE, true);
    }
    
    @Bean
    public Binding dlxBinding() {
        return BindingBuilder.bind(dlxQueue())
                .to(dlxExchange())
                .with(DLX_ROUTING_KEY);
    }
    ```
  - 预期效果：摘要生成失败的消息进入死信队列，可以在管理页面查看
- **核心知识点**：
  - 学习内容：死信队列（消息被拒绝/过期/队列满时进入死信）、延迟队列（TTL + 死信实现）、消息幂等性
  - 学习资源：[RabbitMQ - Dead Letter Exchanges](https://www.rabbitmq.com/dlx.html)（官方文档）
- **LeetCode刷题**：
  - 题目：[102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)（考察：BFS）
- **今日检查项**：
  - [ ] 手动拒绝一条消息，能看到它进入死信队列
  - [ ] 能在 RabbitMQ 管理页面看到死信队列和消息
- **常见问题与解决方案**：
  - 消息没有进入死信队列：检查 `x-dead-letter-exchange` 是否配置正确
  - 死信队列消息没有被消费：添加 `@RabbitListener(queues = DLX_QUEUE)` 消费死信消息
