### 第 3 周 星期三（第 13 天）
- **今日目标**：实现文章发布异步生成 AI 摘要（发布后不阻塞，等摘要生成完再更新）
- **项目改造任务**：
  - 修改文件：`blog/src/main/java/com/blog/blog/config/RabbitMQConfig.java`
    ```java
    // 新增常量
    public static final String SUMMARY_EXCHANGE = "blog.summary.exchange";
    public static final String SUMMARY_QUEUE = "blog.summary.queue";
    public static final String SUMMARY_ROUTING_KEY = "blog.summary.generate";
    
    @Bean
    public TopicExchange summaryExchange() {
        return new TopicExchange(SUMMARY_EXCHANGE);
    }
    
    @Bean
    public Queue summaryQueue() {
        return new Queue(SUMMARY_QUEUE, true);
    }
    
    @Bean
    public Binding summaryBinding() {
        return BindingBuilder.bind(summaryQueue())
                .to(summaryExchange())
                .with(SUMMARY_ROUTING_KEY);
    }
    ```
  - 修改文件：`blog/src/main/java/com/blog/blog/service/impl/ArticleServiceImpl.java`
    ```java
    // 修改 createArticle 方法：去掉直接调用 DeepSeek，改为发消息
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    @Override
    public Article createArticle(String title, String content, Long userId, String categoryId) {
        Article article = new Article();
        article.setTitle(title);
        article.setContent(content);
        article.setUserId(userId);
        article.setCategoryId(categoryId);
        article.setCreateTime(LocalDateTime.now());
        article.setUpdateTime(LocalDateTime.now());
        article = articleRepository.save(article);
        
        // 发消息到 MQ，异步生成摘要
        Map<String, Object> msg = new HashMap<>();
        msg.put("articleId", article.getId());
        msg.put("content", content);
        rabbitTemplate.convertAndSend(
                RabbitMQConfig.SUMMARY_EXCHANGE,
                RabbitMQConfig.SUMMARY_ROUTING_KEY,
                msg
        );
        
        redisUtil.delete(ARTICLE_LIST_KEY);
        return article;
    }
    ```
  - 新建文件：`blog/src/main/java/com/blog/blog/service/SummaryConsumer.java`
    ```java
    @Component
    @Slf4j
    public class SummaryConsumer {
        @Autowired
        private ArticleRepository articleRepository;
        @Autowired
        private DeepSeekService deepSeekService;
        @Autowired
        private RedisUtil redisUtil;
        
        @RabbitListener(queues = RabbitMQConfig.SUMMARY_QUEUE)
        @Transactional
        public void handleSummaryGeneration(Map<String, Object> message) {
            Long articleId = ((Number) message.get("articleId")).longValue();
            String content = (String) message.get("content");
            
            log.info("开始异步生成文章摘要，articleId={}", articleId);
            
            try {
                String summary = deepSeekService.generateSummary(content);
                Article article = articleRepository.findById(articleId)
                        .orElseThrow(() -> new RuntimeException("文章不存在"));
                article.setSummary(summary);
                articleRepository.save(article);
                
                // 更新缓存
                String key = "blog:article:detail:" + articleId;
                redisUtil.set(key, article, 1800);
                
                log.info("文章摘要生成完成，articleId={}", articleId);
            } catch (Exception e) {
                log.error("摘要生成失败，articleId={}", articleId, e);
                // 失败后可以重试或记录到死信队列
            }
        }
    }
    ```

- **常见问题与解决方案**：
  - 消息消费失败导致消息一直重试：配置重试次数上限 `spring.rabbitmq.listener.simple.retry.max-attempts=3`
  - `Message` 中的 `articleId` 是 Integer 还是 Long：Jackson 反序列化数字默认是 Integer，需要 `.longValue()` 转型
