## 一、必须掌握

### 1.1 数组

#### 二分查找（模板 + 力扣 704）

二分查找的前提是数组有序。关键在于统一区间边界约定：以下采用"左闭右闭" `[left, right]`，故循环条件为 `left <= right`，缩边界时 `mid - 1` / `mid + 1`。

```java
// 力扣 704. 二分查找
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2; // 防溢出
            if (nums[mid] == target) return mid;
            else if (nums[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
}
```

#### 双指针（力扣 283 移动零、力扣 15 三数之和）

快慢双指针做原地搬移；对撞双指针配合排序处理三数之和去重。

```java
// 力扣 283. 移动零（同向快慢指针）
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                int t = nums[slow]; nums[slow] = nums[fast]; nums[fast] = t;
                slow++;
            }
        }
    }
}
```

```java
// 力扣 15. 三数之和（排序 + 对撞双指针）
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) break;          // 最小值已 >0，不可能凑出 0
            if (i > 0 && nums[i] == nums[i - 1]) continue; // 去重
            int l = i + 1, r = nums.length - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum == 0) {
                    res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l + 1]) l++; // 去重
                    while (l < r && nums[r] == nums[r - 1]) r--;
                    l++; r--;
                } else if (sum < 0) l++;
                else r--;
            }
        }
        return res;
    }
}
```

#### 滑动窗口（力扣 3 无重复字符最长子串、力扣 209 长度最小子数组）

滑动窗口用左右指针维护一个窗口，右指针扩张、左指针收缩，根据题意在窗口满足条件时更新答案。

```java
// 力扣 3. 无重复字符的最长子串
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> last = new HashMap<>();
        int left = 0, max = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            if (last.containsKey(c)) {
                left = Math.max(left, last.get(c) + 1); // 跳过重复字符
            }
            last.put(c, right);
            max = Math.max(max, right - left + 1);
        }
        return max;
    }
}
```

```java
// 力扣 209. 长度最小的子数组
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int left = 0, sum = 0, min = Integer.MAX_VALUE;
        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];
            while (sum >= target) {            // 满足条件，收缩左边界找更短
                min = Math.min(min, right - left + 1);
                sum -= nums[left++];
            }
        }
        return min == Integer.MAX_VALUE ? 0 : min;
    }
}
```

**面试题："二分查找的边界条件怎么处理？"**

关键是固定区间约定：用左闭右闭 `[l, r]` 时 `while (l <= r)`，命中后 `r = mid - 1`、`l = mid + 1`；用左闭右开 `[l, r)` 时 `while (l < r)`，`r = mid`、`l = mid + 1`。算 mid 用 `l + (r - l) / 2` 防整数溢出。找第一个/最后一个满足条件的位置时，只在真正命中时不立刻返回，而是收紧边界继续逼近。

### 1.2 链表

链表题的套路是：画清指针走向、用 dummy 头节点简化头插、用快慢指针解决环与中点问题。

#### 反转链表（迭代 + 递归）

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

class Solution {
    // 迭代：三指针逐个翻转
    public ListNode reverseList(ListNode head) {
        ListNode prev = null, curr = head;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }

    // 递归：先反转后面的，再把当前接到末尾
    public ListNode reverseListRec(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode newHead = reverseListRec(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}
```

#### 合并两个有序链表（力扣 21）

```java
class Solution {
    public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0), cur = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
            else { cur.next = l2; l2 = l2.next; }
            cur = cur.next;
        }
        cur.next = (l1 != null) ? l1 : l2; // 接上剩余
        return dummy.next;
    }
}
```

#### 环检测（力扣 141 快慢指针）

```java
class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true; // 快慢相遇则有环
        }
        return false;
    }
}
```

**面试题："如何检测链表有环？"**

用快慢指针：慢指针走一步、快指针走两步，若存在环，快指针一定会从后面追上慢指针（相遇）；若快指针走到 null 则无环。原理是若有环，快指针每轮相对慢指针多走一步，差距会逐步缩小到 0。要找环入口，相遇后让一个指针回到头，两指针同速再走，再次相遇点即入口。

### 1.3 二叉树

#### 前中后序遍历（递归 + 迭代）

递归版简洁；迭代版用栈模拟，前序最直观，中序需先把左子树全部压栈，后序可用"根右左"反转或双栈。

```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int x) { val = x; }
}

class Solution {
    // 前序递归
    public List<Integer> preorder(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        preorder(root, res);
        return res;
    }
    private void preorder(TreeNode node, List<Integer> res) {
        if (node == null) return;
        res.add(node.val);
        preorder(node.left, res);
        preorder(node.right, res);
    }

    // 中序迭代：先把左子树一路压栈
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) { stack.push(cur); cur = cur.left; }
            cur = stack.pop();
            res.add(cur.val);
            cur = cur.right;
        }
        return res;
    }

    // 后序迭代：根右左 反转 = 左右根
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        if (root == null) return res;
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);            // 根
            if (node.left != null) stack.push(node.left);
            if (node.right != null) stack.push(node.right);
        }
        Collections.reverse(res);         // 反转得到 左右根
        return res;
    }
}
```

#### 层序遍历（BFS，力扣 102）

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<TreeNode> q = new LinkedList<>();
        q.offer(root);
        while (!q.isEmpty()) {
            int size = q.size();         // 一次取一层
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

#### 最近公共祖先（力扣 236）

后序递归：在左右子树分别找 p、q，若分散在两侧则当前节点就是 LCA。

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        if (left != null && right != null) return root; // 一左一右，当前即 LCA
        return left != null ? left : right;             // 都在一侧
    }
}
```

**面试题："二叉树的非递归遍历怎么写？"**

用栈模拟递归的调用栈。前序：访问根→右入栈→左入栈；中序：一路把左子树压栈，弹出时访问并转向右子树；后序：用"根→右→左"的反向先序遍历，结果反转即得后序。关键是利用栈的 LIFO 改变访问顺序。

### 1.4 排序

#### 快排（partition + 代码）

选基准、把小于基准的放左、大于放右，再对左右子区间递归。

```java
class Solution {
    public void quickSort(int[] nums, int l, int r) {
        if (l >= r) return;
        int p = partition(nums, l, r);
        quickSort(nums, l, p - 1);
        quickSort(nums, p + 1, r);
    }

    private int partition(int[] nums, int l, int r) {
        int pivot = nums[l];
        while (l < r) {
            while (l < r && nums[r] >= pivot) r--;
            nums[l] = nums[r];
            while (l < r && nums[l] <= pivot) l++;
            nums[r] = nums[l];
        }
        nums[l] = pivot;
        return l;
    }
}
```

#### 归并排序（分治 + 代码）

分到单元素再两两合并，合并时借助临时数组。

```java
class Solution {
    public void mergeSort(int[] nums, int l, int r) {
        if (l >= r) return;
        int mid = l + (r - l) / 2;
        mergeSort(nums, l, mid);
        mergeSort(nums, mid + 1, r);
        merge(nums, l, mid, r);
    }

    private void merge(int[] nums, int l, int mid, int r) {
        int[] tmp = new int[r - l + 1];
        int i = l, j = mid + 1, k = 0;
        while (i <= mid && j <= r) {
            tmp[k++] = nums[i] <= nums[j] ? nums[i++] : nums[j++];
        }
        while (i <= mid) tmp[k++] = nums[i++];
        while (j <= r) tmp[k++] = nums[j++];
        System.arraycopy(tmp, 0, nums, l, tmp.length);
    }
}
```

#### 堆排（大顶堆 + 代码）

先建大顶堆，再把堆顶与末尾交换、缩小堆、下沉调整。

```java
class Solution {
    public void heapSort(int[] nums) {
        int n = nums.length;
        for (int i = n / 2 - 1; i >= 0; i--) heapify(nums, n, i); // 建堆
        for (int i = n - 1; i > 0; i--) {
            int t = nums[0]; nums[0] = nums[i]; nums[i] = t;     // 堆顶放末尾
            heapify(nums, i, 0);                                 // 缩小堆并调整
        }
    }

    private void heapify(int[] nums, int n, int i) {
        int largest = i, l = 2 * i + 1, r = 2 * i + 2;
        if (l < n && nums[l] > nums[largest]) largest = l;
        if (r < n && nums[r] > nums[largest]) largest = r;
        if (largest != i) {
            int t = nums[i]; nums[i] = nums[largest]; nums[largest] = t;
            heapify(nums, n, largest);
        }
    }
}
```

#### 复杂度与稳定性对比

| 排序 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 快排 | O(NlogN) | O(N²) | O(logN) | 不稳定 |
| 归并 | O(NlogN) | O(NlogN) | O(N) | 稳定 |
| 堆排 | O(NlogN) | O(NlogN) | O(1) | 不稳定 |

**面试题："快排为什么比归并快？"**

虽然都是 O(NlogN)，但快排在工程上更快：一是常数小，partition 是原地交换、不需要额外数组；二是缓存友好，顺序访问比归并的跳跃合并更利于 CPU 缓存命中；三是空间省，归并需 O(N) 辅助数组。代价是快排最坏会退化到 O(N²)，可通过随机化基准或三数取中规避。

### 1.5 哈希

#### 两数之和（力扣 1）

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>(); // 值 -> 下标
        for (int i = 0; i < nums.length; i++) {
            if (map.containsKey(target - nums[i])) {

            map.put(nums[i], i);
        }
        return new int[0];
    }
```

#### 最长连续序列（力扣 128）

把数放进集合，只从"序列起点"（num-1 不在集合中）开始向上数，避免重复枚举，整体 O(N)。

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int n : nums) set.add(n);
        int max = 0;
        for (int n : set) {
            if (set.contains(n - 1)) continue; // 不是起点，跳过
            int cur = n, len = 1;
            while (set.contains(cur + 1)) { cur++; len++; }
            max = Math.max(max, len);
        }
        return max;
    }
}
```

## 二、进阶

### 2.1 动态规划

DP 的核心是把问题拆成子问题、定义状态、找转移方程、确定边界与遍历顺序。

#### 0-1 背包问题

`dp[i][j]` 表示前 i 个物品、容量 j 时的最大价值，每个物品选或不选。

```java
// 0-1 背包：空间优化为一维，倒序遍历容量防止重复选取
class Solution {
    public int knapsack(int[] weight, int[] value, int capacity) {
        int n = weight.length;
        int[] dp = new int[capacity + 1];
        for (int i = 0; i < n; i++) {
            for (int j = capacity; j >= weight[i]; j--) { // 倒序
                dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
            }
        }
        return dp[capacity];
    }
}
```

#### 最长递增子序列（力扣 300）

`dp[i]` 表示以 nums[i] 结尾的最长递增子序列长度。可再配合二分把整体优化到 O(NlogN)。

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] dp = new int[nums.length];
        int max = 0;
        for (int i = 0; i < nums.length; i++) {
            dp[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
            }
            max = Math.max(max, dp[i]);
        }
        return max;
    }
}
```

#### 买卖股票最佳时机（力扣 121）

`dp[i][0]` 表示第 i 天不持有的最大利润，`dp[i][1]` 表示持有的最大利润。

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[][] dp = new int[n][2];
        dp[0][0] = 0;            // 第一天不持有
        dp[0][1] = -prices[0];  // 第一天买入
        for (int i = 1; i < n; i++) {
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]); // 卖出或保持
            dp[i][1] = Math.max(dp[i - 1][1], -prices[i]);               // 买入或保持
        }
        return dp[n - 1][0];
    }
}
```

**面试题："DP 的解题步骤是什么？"**

第一步明确状态定义（dp 数组每个维度代表什么）；第二步写状态转移方程，思考当前状态由哪些前置状态推出；第三步确定边界初值；第四步确定遍历顺序（依赖关系决定从前往后还是从后往前、几维嵌套）；第五步举例推导验证。

### 2.2 图

#### 拓扑排序（BFS / 力扣 207 课程表）

对 DAG 用入度 BFS：入度为 0 的节点入队，每次出队并把后继节点入度减一，为零则入队，最终访问数等于节点数则无环。

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        int[] indegree = new int[numCourses];
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        for (int[] p : prerequisites) {
            graph.get(p[1]).add(p[0]);
            indegree[p[0]]++;
        }
        Queue<Integer> q = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) if (indegree[i] == 0) q.offer(i);
        int count = 0;
        while (!q.isEmpty()) {
            int course = q.poll();
            count++;
            for (int next : graph.get(course)) {
                if (--indegree[next] == 0) q.offer(next);
            }
        }
        return count == numCourses;
    }
}
```

#### Dijkstra 最短路径（优先队列）

单源最短路径，边权非负。用小顶堆每次取当前距离最小的节点松弛邻居。

```java
class Solution {
    public int[] dijkstra(int n, List<int[]>[] graph, int src) {
        int[] dist = new int[n];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[src] = 0;
        // [节点, 距离]，按距离升序
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
        pq.offer(new int[]{src, 0});
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int u = cur[0], d = cur[1];
            if (d > dist[u]) continue;             // 已有更优解，跳过
            for (int[] edge : graph[u]) {
                int v = edge[0], w = edge[1];
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.offer(new int[]{v, dist[v]});
                }
            }
        }
        return dist;
    }
}
```

### 2.3 堆

#### TopK 问题（小顶堆，力扣 215 第 K 大）

求第 K 大用小顶堆维护 K 个元素：遍历数把大的塞进堆，堆满后比堆顶小的直接丢，更大的弹出堆顶再入堆，最终堆顶就是第 K 大。

```java
class Solution {
    // 力扣 215. 数组中的第 K 个最大元素
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(); // 小顶堆
        for (int num : nums) {
            minHeap.offer(num);
            if (minHeap.size() > k) minHeap.poll(); // 维持堆大小为 K
        }
        return minHeap.peek();
    }
}
```

#### 合并 K 个有序链表（力扣 23）

把每个链表头节点放进小顶堆，每次取最小节点接到结果链，再推入该链的下一个节点。

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;
        PriorityQueue<ListNode> heap = new PriorityQueue<>(Comparator.comparingInt(a -> a.val));
        for (ListNode node : lists) {
            if (node != null) heap.offer(node);
        }
        ListNode dummy = new ListNode(0), cur = dummy;
        while (!heap.isEmpty()) {
            ListNode node = heap.poll();
            cur.next = node;
            cur = cur.next;
            if (node.next != null) heap.offer(node.next); // 该链下一个入堆
        }
        return dummy.next;
    }
}
```

**面试题："求 TopK 用什么数据结构？"**

用堆。求前 K 大用小顶堆维护 K 个元素，遍历时只在与堆顶比较后决定是否替换，时间 O(NlogK)、空间 O(K)，比全排序 O(NlogN) 更省。海量数据求 TopK 可加分治：每台机器各自求本地 TopK，再合并这些 TopK。Java 中直接用 `PriorityQueue`（默认小顶堆，加反转 Comparator 变大顶堆）。
