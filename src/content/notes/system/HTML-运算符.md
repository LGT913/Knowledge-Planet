### 运算符

* 算术运算符

  | 算术运算符 | 说明     |
  | ---------- | -------- |
  | +          | 加法运算 |
  | -          | 减法运算 |
  | *          | 乘法运算 |
  | /          | 除法运算 |
  | %          | 取余数   |
  | ++         | 自增     |
  | --         | 自减     |

* 赋值运算符

  | 赋值运算符 | 说明     |
  | ---------- | -------- |
  | =          | 加法运算 |
  | +=         | 减法运算 |
  | -=         | 乘法运算 |
  | *=         | 除法运算 |
  | /=         | 取余数   |
  | %=         | 自增     |

* 比较运算符

  | 比较运算符 | 说明                     |
  | ---------- | ------------------------ |
  | ==         | 判断值是否相等           |
  | ===        | 判断数据类型和值是否相等 |
  | >          | 大于                     |
  | >=         | 大于等于                 |
  | <          | 小于                     |
  | <=         | 小于等于                 |
  | !=         | 不等于                   |

* 逻辑运算符

  | 逻辑运算符 | 说明               |
  | ---------- | ------------------ |
  | &&         | 逻辑与，并且的功能 |
  | \|\|       | 逻辑或，或者的功能 |
  | !          | 取反               |

* **三元运算符**
  * 三元运算符格式：(比较表达式) ? 表达式1 : 表达式2; 
  * 格式说明：
    如果比较表达式为true，则取表达式1
    如果比较表达式为false，则取表达式2
