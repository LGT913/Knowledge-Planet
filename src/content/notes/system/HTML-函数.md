### 函数

函数类似于 java 中的方法，可以将一些代码进行抽取，达到复用的效果

* 定义格式：

  ```js
  function 方法名(参数列表) {
      方法体; 
      return 返回值; 
  }
  ```

* 调用：

  ```js
  let 变量 = 方法名();
  方法名();
  ```

* 可变参数：

  ```js
  function 方法名(... 参数名) {
      方法体; 
      return 返回值; 
  }
  ```

* 匿名函数

  ```js
  function(参数列表) {
      方法体; 
  }
  ```
