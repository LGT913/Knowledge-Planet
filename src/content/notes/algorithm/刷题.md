## 面试鸭使用专属技巧（最大化效率）

1. **按分类刷题**：严格跟着复习路线，先刷对应模块题库，不要乱刷 例：学 JUC → 直接打开面试鸭「Java 并发」分类，全部刷完再进下一模块
2. **使用「面试模拟」功能**：遮盖答案口述回答，模拟真实面试官提问
3. **收藏高频错题**：把不会、答不全的题目加入收藏，每晚复盘一遍
4. **企业题库查漏补缺**：阶段结束后刷目标公司（阿里 / 字节 / 美团）Java 后端真题，匹配真实面试风格
5. **SQL 专项单独刷**：MySQL 模块同步刷面试鸭 SQL 手写编程题，应对笔试 SQL 大题

## 避坑关键规则

1. **八股不能只背**：每道题要能讲清底层原理，结合你做过的 LeetCode 数据结构举例（如 HashMap 对应两数之和）
2. **算法不能只看题解**：每道题独立手写完整 Java 代码，面试要求现场手撕
3. **同步推进不脱节**：不要先背完所有八股再刷题，两者同步，知识点立刻用代码落地
4. **优先级划分**：Java 基础→集合→并发→JVM→MySQL→Redis→Spring→分布式，顺序不可颠倒，底层支撑上层框架

## 高频面试核心考点

### 1. 多线程高频

- 线程安全：synchronized、Lock、volatile、ABA 问题、CAS
- 线程池参数：核心线程、最大线程、队列、拒绝策略
- 协程 vs 线程：用户态轻量级，极低内存开销，适合海量 IO 并发
- 死锁产生四条件 + 解决方案

### 2. 高并发优化高频

- 缓存分层：本地缓存→分布式缓存→数据库
- 读写分离、分库分表
- 限流、熔断、降级（Sentinel/Hystrix）
- 异步化：同步转异步提升吞吐

### 3. 分布式高频

- CAP 理论、BASE 最终一致性
- 分布式锁三种实现：Redis、Zookeeper、数据库
- 分布式事务方案：2PC、TCC、本地消息表、可靠消息队列
- 注册中心、负载均衡、服务雪崩、多级缓存一致性
