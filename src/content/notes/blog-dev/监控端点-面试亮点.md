## 一、监控端点（面试亮点）

光有 `printStats()` 打日志还不够，最好能提供一个**接口**随时查看状态。

新建 `com/blog/blog/controller/BloomFilterController.java`：

```java
package com.blog.blog.controller;

import com.blog.blog.common.BloomFilterUtil;
import com.blog.blog.common.Result;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import java.util.HashMap;
import java.util.Map;

@RestController
@RequestMapping("/api/admin/bloom")
public class BloomFilterController {

    @Autowired
    private BloomFilterUtil bloomFilterUtil;

    /**
     * 查看布隆过滤器状态
     */
    @GetMapping("/stats")
    public Result<Map<String, Object>> getStats() {
        Map<String, Object> stats = new HashMap<>();
        stats.put("count", bloomFilterUtil.getCount());
        stats.put("expectedInsertions", 10000L);
        stats.put("falseProbability", 0.01);
        return Result.success(stats);
    }

    /**
     * 手动重建布隆过滤器（管理员接口）
     * @param newCapacity 新的预期容量
     */
    @PostMapping("/rebuild")
    public Result<String> rebuild(@RequestParam Long newCapacity) {
        if (newCapacity == null || newCapacity < 1000) {
            return Result.error("新容量不能小于1000");
        }
        bloomFilterUtil.rebuild(newCapacity);
        return Result.success("重建完成");
    }

    /**
     * 测试：判断一个 ID 是否存在
     */
    @GetMapping("/check/{id}")
    public Result<Boolean> check(@PathVariable Long id) {
        boolean result = bloomFilterUtil.mightContain(id);
        return Result.success(result);
    }
}
```

然后给 `BloomFilterUtil` 加一个 `getCount()` 方法：

```java
public long getCount() {
    return bloomFilter.count();
}
```

`BloomFilterUtil` 完整了：

| 方法               | 用途                     |
| :----------------- | :----------------------- |
| init()             | 启动时加载所有文章 ID    |
| add(Long)          | 新文章加入               |
| mightContain(Long) | 判断是否存在（拦截穿透） |
| getCount()         | 监控端点：查看当前数量   |
| rebuild(long)      | 重建扩容                 |

```java
public void add(Long articleId) {
    bloomFilter.add(articleId);
}

public boolean mightContain(Long articleId) {
    return bloomFilter.contains(articleId);
}

public long getCount() {
    return bloomFilter.count();
}

public void rebuild(long newExpectedInsertions) {
    try {
        redissonClient.getKeys().delete(BLOOM_FILTER_KEY);
        bloomFilter = redissonClient.getBloomFilter(BLOOM_FILTER_KEY);
        bloomFilter.tryInit(newExpectedInsertions, FALSE_PROBABILITY);

        List<Long> allIds = articleRepository.findAllIds();
        for (Long id : allIds) {
            bloomFilter.add(id);
        }
        log.info("布隆过滤器重建完成，新容量：{}，实际加载：{}", newExpectedInsertions, allIds.size());
    } catch (Exception e) {
        log.error("布隆过滤器重建失败", e);
        throw new RuntimeException("布隆过滤器重建失败", e);
    }
}
```

#### 问题 1：BloomFilterController 硬编码了常量值

**修改**：让 `BloomFilterUtil` 暴露这两个常量，Controller 引用：

在 BloomFilterUtil.java 里加两个 getter：

```java
public long getExpectedInsertions() {
    return EXPECTED_INSERTIONS;
}

public double getFalseProbability() {
    return FALSE_PROBABILITY;
}
```

然后 Controller 改成：

```java
stats.put("expectedInsertions", bloomFilterUtil.getExpectedInsertions());
stats.put("falseProbability", bloomFilterUtil.getFalseProbability());
```

#### 问题 2：BloomFilterUtil 的 `rebuild()` 方法没有异常保护

BloomFilterUtil.java：加 try-catch，失败时恢复或至少报警：

```java
public void rebuild(long newExpectedInsertions) {
    try {
        redissonClient.getKeys().delete(BLOOM_FILTER_KEY);
        bloomFilter = redissonClient.getBloomFilter(BLOOM_FILTER_KEY);
        bloomFilter.tryInit(newExpectedInsertions, FALSE_PROBABILITY);

        List<Long> allIds = articleRepository.findAllIds();
        for (Long id : allIds) {
            bloomFilter.add(id);
        }
        log.info("布隆过滤器重建完成，新容量：{}，实际加载：{}", newExpectedInsertions, allIds.size());
    } catch (Exception e) {
        log.error("布隆过滤器重建失败", e);
        throw new RuntimeException("布隆过滤器重建失败", e);
    }
}
```

### 问题 3：字段注入 → 构造器注入（3 个类）

企业规范推荐构造器注入（更易测试、不可变依赖、循环依赖检测）。需要改的类：

**BloomFilterUtil.java**：

```java
// 改前
@Autowired
private RedissonClient redissonClient;
@Autowired
private com.blog.blog.repository.ArticleRepository articleRepository;

// 改后
private final RedissonClient redissonClient;
private final com.blog.blog.repository.ArticleRepository articleRepository;

public BloomFilterUtil(RedissonClient redissonClient,
                       com.blog.blog.repository.ArticleRepository articleRepository) {
    this.redissonClient = redissonClient;
    this.articleRepository = articleRepository;
}
```

**BloomFilterController.java**：

```java
// 改前
@Autowired
private BloomFilterUtil bloomFilterUtil;

// 改后
private final BloomFilterUtil bloomFilterUtil;

public BloomFilterController(BloomFilterUtil bloomFilterUtil) {
    this.bloomFilterUtil = bloomFilterUtil;
}
```

**ArticleController.java**：

```java
// 改前

@Autowired
```

### 问题 4：BloomFilterController 的 check 接口加边界保护

如果用户传了负数 ID（如 `-1`），布隆过滤器会判断为"可能存在"（因为布隆过滤器是概率性的），然后继续查缓存+DB。虽然不会出错，但可以加个快速拦截：

```java
@GetMapping("/check/{id}")
public Result<Boolean> check(@PathVariable Long id) {
    if (id == null || id <= 0) {
        return Result.success(false);
    }
    boolean result = bloomFilterUtil.mightContain(id);
    return Result.success(result);
}
```
