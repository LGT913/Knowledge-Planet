### 步骤 5：点赞定时同步任务

**文件**：`service/impl/ArticleServiceImpl.java`

**设计思路**：
- 每 10 分钟执行一次（`fixedRate = 600_000`），初始延迟 2 分钟
- 分布式锁（Redisson）防止多实例同时执行
- 读取 Redis 中实时点赞计数，**直接覆盖** DB 值（兜底修复 MQ 丢失导致的数据不一致）
- 只同步脏文章集合中的文章，避免全表扫描

```java
@Override
@Scheduled(initialDelay = 120_000, fixedRate = 600_000)
@Transactional(rollbackFor = Exception.class)
public void syncLikeCountToDB() {
    String lockKey = BlogCacheConstants.LIKE_SYNC_LOCK;
    RLock lock = redisUtil.getLock(lockKey);
    boolean locked = false;
    try {
        locked = lock.tryLock(5, -1, TimeUnit.SECONDS);
        if (!locked) {
            log.info("点赞同步任务正在执行，跳过本次定时任务");
            return;
        }

        Set<Object> dirtyIdSet = redisUtil.smembers(BlogCacheConstants.ARTICLE_LIKE_DIRTY_KEY);
        if (Objects.isNull(dirtyIdSet) || dirtyIdSet.isEmpty()) {
            return;
        }

        log.info("开始同步文章点赞数据，待同步文章数量：{}", dirtyIdSet.size());
        int success = 0, fail = 0;

        for (Object idObj : dirtyIdSet) {
            Long articleId;
            try {
                articleId = Long.valueOf(idObj.toString());
            } catch (NumberFormatException e) {
                log.error("脏数据ID格式非法，丢弃：{}", idObj);
                fail++;
                continue;
            }

            try {
                Object countObj = redisUtil.get(BlogCacheConstants.ARTICLE_LIKE_COUNT_KEY + articleId);
                int realLikeCount = countObj instanceof Number ? ((Number) countObj).intValue() : 0;
                articleRepository.updateLikeCount(articleId, realLikeCount);
                success++;
                redisUtil.srem(BlogCacheConstants.ARTICLE_LIKE_DIRTY_KEY, articleId);
            } catch (Exception e) {
                log.error("同步点赞数失败，文章ID：{}", articleId, e);
                fail++;
            }
        }
        log.info("点赞同步任务执行完成，成功：{}，失败：{}", success, fail);
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    } finally {
        if (locked && lock.isHeldByCurrentThread()) {
            lock.unlock();
        }
    }
}
```

### 步骤 6：浏览记录生产者（嵌入 ArticleController）

**文件**：`controller/ArticleController.java`（第 78-91 行）

**设计思路**：
- 嵌入在文章详情接口 `GET /api/article/{id}` 中
- 只对登录用户记录浏览历史（`principal != null`）
- Redis List 先写（LPUSH + LTRIM），MQ 消息异步发

```java
@GetMapping("/{id}")
public Result<Article> getArticle(@PathVariable Long id,
        @AuthenticationPrincipal UserPrincipal principal) {
    Article article = articleService.getArticle(id);
    articleService.incrementViewCount(id);

    // 登录用户 → 记录浏览历史
    if (principal != null) {
        Long userId = principal.getUserId();
        String historyKey = BlogCacheConstants.USER_HISTORY_KEY + userId;

        // Redis 先写：最新浏览在前，最多保留 50 条
        redisUtil.lPush(historyKey, id);
        redisUtil.lTrim(historyKey, 0, BlogCacheConstants.USER_HISTORY_MAX - 1);
        redisUtil.sadd(BlogCacheConstants.USER_HISTORY_DIRTY_KEY, userId);

        // 发送 MQ 异步持久化
        BrowseHistoryMessage msg = new BrowseHistoryMessage();
        msg.setUserId(userId);
        msg.setArticleId(id);
        msg.setTimestamp(System.currentTimeMillis());
        rabbitTemplate.convertAndSend(RabbitMQConfig.HISTORY_EXCHANGE,
                RabbitMQConfig.HISTORY_ROUTING_KEY, msg);
    }

    return Result.success(article);
}
```
