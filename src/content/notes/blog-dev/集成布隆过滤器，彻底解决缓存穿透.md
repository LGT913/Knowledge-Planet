# 集成布隆过滤器，彻底解决缓存穿透

### 一、布隆过滤器的原理

布隆过滤器是一个**位数组 + 多个哈希函数**的数据结构。

**核心特性**：**布隆过滤器说不存在的，一定不存在；说存在的，可能不存在。**

### 二、布隆过滤器怎么防穿透

```
请求进来
   │
   ▼
布隆过滤器判断：这个 ID 存在吗？
   ├── 一定不存在 → 直接返回"文章不存在"，不查缓存，不查数据库 ✅ 穿透被拦住
   └── 可能存在 → 继续走正常流程（查缓存 → 查DB）
                     ↑
                可能有误判，但概率很小（比如1%）
                误判了也没关系，查DB没查到就返回
```
