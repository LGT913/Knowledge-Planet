## 七、关键问题排查记录

### 问题 1：`spring-cloud-starter-gateway:jar:unknown` 找不到

**根因**：Spring Cloud 版本号写错（`4.3.0` 应为 `2025.0.0`）。

**教训**：Spring Cloud 使用年份版本号，不是语义版本。

### 问题 2：`com.fasterxml.jackson.datatype.jsr310` 包不存在

**根因**：SB 4.x 中 Jackson 从 `com.fasterxml.jackson` 迁移到 `tools.jackson`。

**解决**：降级到 SB 3.5.4 后自动恢复。

### 问题 3：`jackson-datatype-jsr310:jar` version missing

**根因**：父 POM 的 `<dependencyManagement>` 声明了空 version，覆盖了 BOM 的版本管理。

**解决**：删除父 POM 中整段 `jackson-datatype-jsr310` 的 dependencyManagement 声明，让 `spring-boot-dependencies` BOM 管理。

**Maven 依赖调解规则**：`dependencyManagement` 直接声明 > BOM 导入。空 version 声明不等于"不管理"，而是"管理为 null"。

### 问题 4：`Could not resolve placeholder 'jwt.secret-key'`

**三层根因**：

| 层级 | 原因 | 修复 |
|------|------|------|
| 依赖 | 未引入 `spring-cloud-starter-bootstrap` | 补全依赖 |
| 语法 | `data-id` 写成横杠 | 改为 `dataId` |
| 环境 | Docker Nacos 无持久化 | 挂载数据卷 |

### 问题 5：Redis AUTH 空密码拒绝连接

**根因**：`password：[已隐藏] 无环境变量时解析为空字符串 `""`，客户端发送 `AUTH ""` 被拒绝。

**解决**：`password：[已隐藏] 是 SpEL 表达式，解析为 Java null。

### 问题 6：article-service 启动失败，找不到 RedissonClient Bean

**根因**：`application.yml` 残留了 `RedissonAutoConfigurationV2` 排除，但 `RedisConfig` 没有手动创建 `RedissonClient` Bean。

**解决**：删除排除配置，让 `redisson-spring-boot-starter` 自动装配。

### 问题 7：IDE 静态检查误报

**现象**：
- `GenericJackson2JsonRedisSerializer` 构造器标红（实际合法）
- `bootstrap.yml` 的 `shared-configs` 全部标红（无配置元数据）
- `dataId` 属性无法解析（IDE 不认识 Nacos 扩展属性）

**原则**：以命令行编译 + 启动日志为准，IDE 警告仅作参考。

### 问题 8：Docker Nacos 容器删除后配置丢失

**解决**：挂载数据卷持久化：

```powershell
docker run -d --name nacos -p 8848:8848 -p 9848:9848 `
  -e MODE=standalone `
  -v D:\docker-data\nacos:/home/nacos/data `
  nacos/nacos-server:v2.4.1
```

> PowerShell 换行符是反引号 `` ` ``，CMD 是 `^`，两者不通用。

### 问题 9：Docker 容器内访问宿主机 MySQL

不能用 `127.0.0.1` 或 `localhost`，必须用 `host.docker.internal`。
