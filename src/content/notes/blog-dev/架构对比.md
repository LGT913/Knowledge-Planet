## 一、架构对比

### 改造前（单体）

```
blog/
├── src/main/java/com/blog/blog/
│   ├── controller/          # 用户、文章、分类、评论 Controller
│   ├── service/             # 所有业务逻辑
│   ├── repository/          # 所有数据访问
│   ├── entity/              # 所有实体
│   ├── config/              # Security、Redis、RabbitMQ
│   ├── common/              # 统一返回、异常处理
│   └── util/                # Redis、JWT 工具
├── pom.xml                  # 单一依赖管理
└── application.yml          # 单一配置文件
```

**问题**：一个 `mvn package` 打包所有代码，任何模块改动都需全量部署。

### 改造后（微服务）

```
blog-cloud/
├── pom.xml                               # 父 POM：统一版本管理
├── blog-common/                          # 公共模块：Result、PageResult、异常
│   ├── pom.xml
│   └── src/main/java/com/blog/common/
│       ├── result/Result.java
│       ├── vo/PageResult.java
│       └── exception/GlobalExceptionHandler.java
├── blog-gateway/                         # 网关：路由分发 + 跨域（8080）
│   ├── pom.xml
│   ├── bootstrap.yml
│   └── application.yml
├── blog-user-service/                    # 用户服务：登录/注册（8081）
│   ├── pom.xml
│   ├── bootstrap.yml
│   ├── application.yml
│   └── src/main/java/com/blog/user/
│       ├── config/RedisConfig.java
│       ├── security/JwtUtil.java
│       ├── util/RedisUtil.java
│       ├── controller/UserController.java
│       ├── service/UserService.java
│       └── repository/UserRepository.java
└── blog-article-service/                 # 文章服务：文章/分类/评论（8082）
    ├── pom.xml
    ├── bootstrap.yml
    ├── application.yml
    ├── src/main/java/com/blog/article/
    │   ├── config/RedisConfig.java
    │   ├── util/RedisUtil.java
    │   ├── controller/ArticleController.java
    │   ├── service/ArticleService.java
    │   └── repository/ArticleRepository.java
```

**核心变化**：

| 维度 | 单体 | 微服务 |
|------|------|--------|
| 部署单元 | 1 个 jar | 4 个独立 jar |
| 配置管理 | 1 个 application.yml | Nacos 共享配置 + 本地配置 |
| 服务通信 | 本地方法调用 | HTTP + Gateway 路由 |
| 依赖管理 | 直接写版本 | 父 POM 统一锁定 |
| 鉴权 | Security 过滤器 | Gateway 统一入口 + 各服务独立 |
| 端口 | 单一 8080 | 8080/8081/8082 |

## 二、版本对齐决策

### 为什么选择 Spring Boot 3.5.4 而不是 4.0.6

| 对比维度 | SB 4.0.6 | SB 3.5.4 |
|---------|----------|----------|
| Jakarta EE | EE 10（包路径大改） | EE 9（稳定） |
| Jackson | 3.x（`tools.jackson`） | 2.x（`com.fasterxml.jackson`） |
| RedisProperties | 改名 `DataRedisProperties` | 原名 `RedisProperties` |
| SCA 2025.0.0.0 | 部分自动配置不兼容 | 完全兼容 |
| Redisson Starter | 自动配置引用旧类名 | 自动配置正常 |
| 单体项目原版本 | 4.0.6 | 3.5.4 |

**结论**：单体项目从 4.0.6 降级到 3.5.4，避免大量兼容 hack。Spring Cloud Alibaba 2025.0.0.0 对 3.5.x 支持最成熟。

### 最终版本矩阵

```
Spring Boot        3.5.4
Spring Cloud       2025.0.0（年份版本号，非语义版本）
Spring Cloud Alibaba 2025.0.0.0
Redisson          3.31.0（redisson-spring-boot-starter）
JJWT              0.12.6
MySQL Connector   9.1.0
Lombok            1.18.34
Java              17
```

### 版本号常见陷阱

- Spring Cloud 用年份版本号（`2025.0.0`），不是语义版本（`4.3.0`）
- Spring Cloud Alibaba 多一位（`2025.0.0.0`），与 Spring Cloud 版本对应
- `jackson-datatype-jsr310` 版本由 `spring-boot-dependencies` BOM 管理，不应手动写 version
