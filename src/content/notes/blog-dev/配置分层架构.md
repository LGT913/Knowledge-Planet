## 四、配置分层架构

### 三层配置模型

```
┌─────────────────────────────────────────┐
│  bootstrap.yml（启动时最先加载）          │
│  - Nacos 地址、命名空间                    │
│  - 指定共享配置 dataId                    │
│  - spring.application.name               │
├─────────────────────────────────────────┤
│  Nacos 公共配置 blog-common.yaml          │
│  - JWT 密钥/过期时间                      │
│  - MySQL 数据源                           │
│  - Redis 连接信息                         │
│  - 多服务共享，一处修改全部生效              │
├─────────────────────────────────────────┤
│  application.yml（服务私有配置）           │
│  - server.port                           │
│  - 日志级别                               │
│  - 服务特有配置                            │
└─────────────────────────────────────────┘
```

### 关键：`spring-cloud-starter-bootstrap`

Spring Cloud 2022+ 默认关闭 bootstrap 上下文，必须手动引入：

```xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-bootstrap</artifactId>
</dependency>
```

### bootstrap.yml 标准写法

```yaml
spring:
  application:
    name: blog-user-service       # 必须：Nacos 注册用
  cloud:
    nacos:
      server-addr: ${NACOS_ADDR:localhost:8848}
      namespace: ${NACOS_NAMESPACE:}
      config:
        file-extension: yaml
        group: DEFAULT_GROUP
        refresh-enabled: true
        shared-configs:
          - dataId: blog-common.yaml      # 注意：驼峰 dataId，不是 data-id
            group: DEFAULT_GROUP
            refresh: true
      discovery:
        ephemeral: true
```

> **常见错误**：写成 `data-id`（横杠）会导致 Nacos 忽略该共享配置，所有公共配置缺失。
